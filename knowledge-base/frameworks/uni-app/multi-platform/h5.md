# uni-app H5 适配安全

## 📋 概述

uni-app 支持编译到 H5 平台，为开发者提供了跨端开发的能力。H5 平台的安全特性与小程序有所不同，需要特别关注 Web 应用的安全问题。了解和正确使用 H5 平台的安全特性对于构建安全的 uni-app 应用至关重要。

## 🎯 核心安全特性

- **Web 安全标准**：H5 平台遵循 Web 安全标准，如 CSP、CORS 等
- **浏览器安全**：H5 平台利用浏览器的安全机制，如同源策略、沙箱等
- **HTTPS 支持**：H5 平台支持 HTTPS，确保数据传输安全
- **Web API 安全**：H5 平台支持安全的 Web API，如 Web Crypto API

## 🔍 常见安全问题

### 问题 1：XSS 攻击

**描述**：在 H5 平台中，如果直接将用户输入的内容插入到 DOM 中，可能导致跨站脚本 (XSS) 攻击。

**风险**：高风险，可能导致恶意脚本执行，用户会话被劫持等严重后果。

**解决方案**：

1. **使用 Vue 的数据绑定**：使用 Vue 的数据绑定 `{{ }}`，它会自动转义
2. **避免使用 v-html**：除非能确保内容是安全的，否则避免使用 `v-html` 指令
3. **验证用户输入**：对所有用户输入进行严格验证和过滤
4. **使用 DOMPurify**：如果必须使用 `v-html`，使用 DOMPurify 清理内容

```vue
<template>
  <view>
    <!-- 安全：使用数据绑定 -->
    <view>{{ userInput }}</view>
    
    <!-- 不安全：直接使用 v-html -->
    <!-- <view v-html="userInput"></view> -->
    
    <!-- 安全：使用 DOMPurify 清理内容 -->
    <view v-html="sanitize(userInput)"></view>
  </view>
</template>

<script setup>
import { ref } from 'vue';
import DOMPurify from 'dompurify';

const userInput = ref('<script>alert("XSS")</script>');

const sanitize = (html) => {
  return DOMPurify.sanitize(html);
};
</script>
```

### 问题 2：CSRF 攻击

**描述**：在 H5 平台中，如果未实施 CSRF 防护，可能导致跨站请求伪造 (CSRF) 攻击。

**风险**：高风险，可能导致未授权操作，数据被篡改，用户会话被劫持等严重后果。

**解决方案**：

1. **实施 CSRF token**：实施 CSRF token 验证，确保请求来自合法来源
2. **使用 SameSite Cookie**：使用 SameSite Cookie 属性，限制 Cookie 的发送范围
3. **验证请求来源**：验证请求的 Origin 和 Referer 头，确保请求来自合法域名

```javascript
// utils/csrf.js
export const getCsrfToken = () => {
  return localStorage.getItem('csrf_token') || generateCsrfToken();
};

export const setCsrfToken = (token) => {
  localStorage.setItem('csrf_token', token);
};

export const generateCsrfToken = () => {
  return Math.random().toString(36).substring(2, 15) + Math.random().toString(36).substring(2, 15);
};

export const validateCsrfToken = (token) => {
  const storedToken = localStorage.getItem('csrf_token');
  return storedToken === token;
};
```

### 问题 3：存储安全

**描述**：在 H5 平台中，如果不当使用存储 API，可能导致敏感信息泄露。

**风险**：中风险，可能导致敏感信息被其他网站访问，信息泄露等后果。

**解决方案**：

1. **避免存储敏感信息**：避免在 localStorage 和 sessionStorage 中存储敏感信息
2. **使用加密存储**：如果必须存储敏感信息，对其进行加密
3. **使用 HttpOnly Cookie**：使用 HttpOnly Cookie 存储敏感信息，避免 JavaScript 访问

```javascript
// utils/storage.js
import CryptoJS from 'crypto-js';

const SECRET_KEY = 'your-secret-key';

export const setSecureStorage = (key, value) => {
  const encryptedValue = CryptoJS.AES.encrypt(JSON.stringify(value), SECRET_KEY).toString();
  localStorage.setItem(key, encryptedValue);
};

export const getSecureStorage = (key) => {
  const encryptedValue = localStorage.getItem(key);
  if (!encryptedValue) {
    return null;
  }
  const bytes = CryptoJS.AES.decrypt(encryptedValue, SECRET_KEY);
  return JSON.parse(bytes.toString(CryptoJS.enc.Utf8));
};

export const removeSecureStorage = (key) => {
  localStorage.removeItem(key);
};
```

### 问题 4：网络请求安全

**描述**：在 H5 平台中，如果网络请求配置不当，可能导致安全问题，如中间人攻击、数据泄露等。

**风险**：中风险，可能导致数据泄露，服务被滥用等后果。

**解决方案**：

1. **使用 HTTPS**：确保所有网络请求都使用 HTTPS 协议
2. **验证证书**：验证 SSL 证书，避免中间人攻击
3. **配置 CORS**：正确配置 CORS，避免跨域安全问题

```javascript
// utils/request.js
export const request = (url, options = {}) => {
  // 验证 URL 是否使用 HTTPS
  if (!url.startsWith('https://')) {
    throw new Error('只允许使用 HTTPS 协议');
  }
  
  // 添加 CSRF token
  const csrfToken = getCsrfToken();
  options.headers = {
    ...options.headers,
    'X-CSRF-Token': csrfToken
  };
  
  // 发送请求
  return uni.request({
    url,
    ...options
  });
};
```
